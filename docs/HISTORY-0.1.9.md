# 0.1.9：历史记录与缓存管理

本次只增加历史入口、文件占用展示与清理，沿用既有最近 30 条已结束任务的保留策略，不更改媒体下载、倍速或压缩策略。

## 使用

侧栏顶部可切换“制作 GIF”和“历史记录”。历史独立于当前素材页面，显示生成时间、片段范围、速度、结果信息和来源链接；支持名称 / 来源搜索与状态筛选。未清理的 GIF 可以预览和保存。

“GIF 本地文件”显示 IndexedDB 中实际保留文件的字节数与个数，包括没有关联记录的遗留成品文件。

| 操作 | 保留内容 | 删除内容 |
| --- | --- | --- |
| 清理缓存 | 历史、来源、参数、结果指标、设置 | 确认时列出的扩展内 GIF 文件 |
| 清空历史 | 运行中 / 排队任务、设置 | 确认时列出的已结束任务及其 GIF 文件 |
| 逐条删除 | 其他任务、设置 | 该已结束任务及其 GIF 文件 |

以上都不删除用户已保存到电脑的文件，也不清 Chrome 的全局缓存或其他网站数据。原始输入和处理临时数据在任务结束后已释放，不虚构可清理的原视频缓存。文件清理后保留历史指标并显示“文件已清理”，取消预览 / 保存入口；可打开来源页面重新生成。

## 实现约定

- 继续使用现有 IndexedDB schema，无数据库重建。可选 `result.clearedAt` 标记文件已清理，旧记录没有该字段仍可读。历史完成状态保留，它描述生成结果，不代表文件永远存在。
- 清理和逐条删除在后台使用覆盖 `jobs` 与 `results` 的单个读写事务。事务内重新检查任务状态，运行中 / 排队记录不删除。实际文件大小通过游标读取 Blob 元信息，不在 UI 线程读取所有媒体字节。
- 用户确认的是 ID 快照。确认期间产生的新结果不在请求中；其他面板先清理了同一文件，后续清理不重复计数。跨面板发布变更，释放相应预览 URL。
- 每次浏览器下载独立拥有临时 Blob URL，已取得文件的下载不依赖 IndexedDB 中的缓存继续存在。下载完成、中断或启动失败后释放该 URL。通过 Chrome 下载记录定位 URL，不依赖易随 Service Worker 休眠丢失的内存映射。
- 下载时的名称更新在事务内读取最新任务，避免覆盖并发清理标记。清理不增加权限、依赖或联网请求。
- 清理对话框使用原生 `dialog.showModal()`，提供焦点约束、Escape 取消和关闭后的焦点返回。所有新增文案进入中英文 Chrome i18n 资源。

接口依据：[IndexedDB transactions](https://developer.mozilla.org/en-US/docs/Web/API/IDBDatabase/transaction)、[原生 dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)、[Chrome downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads)。

## 浏览器回归

`npm run test:history` 使用独立临时 Chrome 配置、真实扩展页面和 IndexedDB、自生成 GIF，验证：

1. 当前页面无素材时仍可进入历史，搜索名称 / 来源、筛选状态、显示时间并读取旧版记录。
2. 430 / 320 px 窄侧栏布局、原生清理确认和取消。
3. 真实浏览器保存的磁盘文件在缓存清理后保持逐字节一致；另一个面板的预览随清理关闭。
4. 清理释放已列出的 GIF / 孤立文件，保留记录与设置；确认之后生成的文件保留，重复清理不重复计数。
5. 已交付下载的 URL 在清理后仍可读取，结束后会释放；已清理文件没有预览 / 保存按钮。
6. 清空历史期间排队和运行中的实际转换不受影响，随后能完成。
7. 浏览器关闭并重开后历史 / 文件仍在；单条删除同步删除两个存储中的对应内容。

本轮 `npm run check`（类型检查、72 项单元 / 契约测试、生产构建）、`test:history`、`test:e2e`、`test:preferences`、`test:download` 均通过。报告与截图位于 `test-results/history/`，历史测试已接入 CI。开发中不读取或清理用户日常 Chrome 的历史、缓存或下载文件。

本轮仍需将 0.1.9 加载到当前 Chrome 安装进行重载验收；代码及安装包未提交、推送或发布。YouTube 等平台既有验证缺口见 [0.1.7 媒体验收](MEDIA-0.1.7.md)，本轮不扩展平台支持。
