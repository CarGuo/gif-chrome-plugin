# Gif Toolkit Chrome v0.1.5

把当前网页的视频、GIF、WebP 选成片段，在本机生成大小合适的 GIF。

**这是预览版，需要 Chrome 148+，通过开发者模式安装，尚未上架 Chrome Web Store。**

## 下载与安装

下载 **`gif-toolkit-chrome-0.1.5.zip`**，解压后打开 `chrome://extensions`，开启开发者模式，加载包含 `manifest.json` 的目录。

升级已有安装时，在原目录更新文件并重载扩展，刷新来源网页、重新打开侧栏，确认版本为 **0.1.5**。GitHub 的 “Source code” 附件用于开发，不能直接加载。

## 功能

- 网页媒体右键和侧栏选择，支持多个素材及多个时间段，每段单独输出。
- 默认选择完整时长，默认 **4 MB / 最长边 800 px / 10 fps / 1×**。
- 速度支持 **0.1–10×**，提供快捷按钮和预计成品时长。
- 新增 **Drop frames / 丢帧**，默认关闭：移除连续重复帧，或每 2 / 3 / 4 帧移除一帧，保持倍速后的总时长。
- 先按速度和尺寸处理，再压缩；仍超限才降帧、缩图并重新压缩，不自动截短片段。
- 本机后台队列、取消、历史、成品预览、重新编辑和批量保存。
- 可编辑标题，保存文件名包含 Base64url、生成时间戳和唯一编号，不含中文或空格。
- 中英文界面、按网站请求权限，无需桌面 FFmpeg 或转码服务器。

## 修复

- 旧默认 12 fps 的一次性迁移与之后自选值的保留。
- GIF / WebP 读取后再次扫描，保留动画时长和用户选区。
- 动画使用整数微秒定位，避免小数边界采到上一帧。
- 调色板统计保留画面的完整颜色，避免周期丢帧后末尾新颜色缺失。
- 显式设置尾帧停留时间，避免丢帧导致结尾缩短或意外加速。
- 并发入队、历史回收与单帧动画时长校验。

## 验证与限制

44 项单元 / 契约测试及本地真实 Chromium 编码验证通过；检查了帧数、逐帧颜色、延时、透明画面、倍速、文件预算和设置恢复。

- 普通网页视频、GIF / 动态 WebP / 透明 WebP 已通过本地端到端测试。
- YouTube 普通公开视频短片段曾在 v0.1.4 验证通过，实际处理受播放器和缓冲影响。
- X 结构和右键适配测试通过；**真实登录态 X 完整流程、Shorts、跨域 iframe 仍待专项验收**。
- 每段最多 600 个调速后的采样帧；不支持 DRM、直播、拼接、裁剪或完整视频下载。
- 取帧时保持来源页面打开；来源播放器会临时定位取帧，随后恢复。

**English:** A local Chrome GIF maker for webpage videos and animated images. Defaults to a full clip, 4 MB, 800 px and 10 fps. Includes speed control, optional frame removal with preserved timing, automatic size optimization, history and safe timestamped filenames. Requires Chrome 148+ and developer-mode installation. This is a preview: full logged-in X, Shorts and cross-origin iframe acceptance is still pending. Download the extension ZIP to install; the companion source ZIP provides the encoder and dependency sources.
