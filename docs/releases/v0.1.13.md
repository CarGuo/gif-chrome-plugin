# Gif Toolkit Chrome v0.1.13

在 v0.1.12 本地视频批量导入的基础上，把入口做得更醒目，并补齐处理完成后的清理方式。要求 Chrome 148+。

- 「从电脑批量导入视频」改为通栏虚线按钮，带上传图标、标题、副说明和加号，位于来源列表标题正下方，一眼可点。
- 处理完成后清理本地视频有三种方式：点视频卡片右侧的「×」单独删除；点列表下方的「清空全部已导入视频」一次清空（正在生成的自动保留，其余清除并提示）；也可在片段区点「移除导入」。
- 删除会同时清掉视频文件本身，已生成并保存的 GIF 不受影响。
- 新增本地视频真实浏览器端到端测试：批量导入 → 生成 GIF → 单个删除 / 全部清空，已接入 CI。

类型检查、单元测试、10 个浏览器端到端脚本、生产构建和发布校验全部通过。本地导入的真实 Chrome 人工验收待完成；此前 X 登录态、YouTube 完整下载及 Shorts 的验收缺口仍保留。

下载 `gif-toolkit-chrome-0.1.13.zip` 并更新原目录，在扩展管理页重载后刷新来源页面。不要卸载重装，以免清除本地历史和已导入的视频。第三方源码 ZIP 用于源码分发；GitHub 自动提供的 Source code 不能直接加载为扩展。
