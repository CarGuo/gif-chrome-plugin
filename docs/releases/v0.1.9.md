# Gif Toolkit Chrome v0.1.9

本次预览版合并 0.1.6–0.1.8 的下载和处理流程改进，并增加历史页、缓存占用和清理功能。需要 **Chrome 148+**，通过开发者模式安装。

## 下载与升级

下载 **`gif-toolkit-chrome-0.1.9.zip`**，解压后在 `chrome://extensions` 加载包含 `manifest.json` 的目录。已有安装请更新原目录并重载，刷新来源网页、重新打开侧栏，确认版本为 **0.1.9**。不要卸载再安装，以免丢失本地历史。

## 主要变化

- **先下载，再处理**：普通文件、Blob、HLS（TS / fMP4）、DASH 与平台解析器取得本地媒体后，统一进行倍速采样、尺寸估算、缩图、GIF 编码和优化；尺寸与优化仍无法达标才自动降帧。媒体处理在 Worker 中运行，不再拖动网页播放器逐帧取图。
- **遵循尺寸上限下载**：多档视频选择最长边不超过设置上限的最大档。默认 800 px 时，原 X 样本选择 576 × 360 档，避免下载 1152 × 720 大档；只有所有档位都超限才下载最小原档再缩小。
- **修复完整选区误报越界**：完整选区以下载文件的实际结尾为准，解决网页时长与文件时长略有差异时出现的 `Choose a valid start and end within the media duration.`。手动截取仍严格校验。
- **减少重复编码**：按倍速后的采样点估算尺寸，复用采样帧并根据实际字节数调整，使用本地 Gifsicle 优化，替换固定参数组合反复全片编码的旧流程。
- **独立历史页**：最近 30 条已结束任务支持搜索、状态筛选、来源链接、预览、保存和逐条删除。
- **清理范围明确**：显示 GIF 文件实际占用；清理缓存删除扩展内 GIF 文件、保留记录，清空历史删除记录及文件。运行中任务、设置和已保存到电脑的文件不受影响。清理后记录标记“文件已清理”。
- 修复后台处理页冷启动并发、跨面板清理同步，以及下载完成后临时文件 URL 的释放。新增文本沿用中英文资源。

默认仍为 **4 MB / 最长边 800 px / 10 fps / 1×**；显式丢帧默认关闭，保留选定速度下的完整时长。

## 验证与限制

本地 72 项单元 / 契约测试、类型检查、生产构建和浏览器回归已通过。tag CI 会重新运行七组浏览器测试、打包及校验，通过后才发布附件。浏览器回归使用隔离素材，不代表所有真实网站均已验收。

- X 公开接口与真实 CDN 下载、下载尺寸选择、网页时长差异回归通过；**已有安装升级后的登录态 X 原生侧栏流程仍待验收**。
- 提供的 OpenAI 页面对应的 Vimeo 视频已通过真实 iframe 来源下载和转换；原页面的完整 iframe 授权 UI 流程仍待验收。
- **YouTube SABR 已接入，但有效会话中的完整下载验收尚未通过；Shorts 仍待专项验收。** 本版不将这些项目标为完成支持。
- 每段调速后最多 600 个采样帧，原始输入最多 128 MiB；不支持 DRM、直播或无法完整获取的来源。未包含原视频单独导出、拼接、裁剪、片段预览或真实缩略图帧条。
- 清理 GIF 缓存后，若要再次保存该结果，需要从来源重新生成；本版不清 Chrome 全局缓存。

详细证据见 [媒体验收](https://github.com/CarGuo/gif-chrome-plugin/blob/v0.1.9/docs/MEDIA-0.1.7.md)、[下载与完整选区修复](https://github.com/CarGuo/gif-chrome-plugin/blob/v0.1.9/docs/DOWNLOAD-0.1.8.md)、[历史与缓存](https://github.com/CarGuo/gif-chrome-plugin/blob/v0.1.9/docs/HISTORY-0.1.9.md)。这些开发记录保留各次验证时的状态，发行范围以本说明为准。

**English:** This preview adds a dedicated history view, storage usage and cache cleanup, and combines the download-first pipeline and duration/representation fixes developed in 0.1.6–0.1.8. Downloads respect the configured size ceiling; complete-source clips use the downloaded file's actual end. Speed sampling and resizing precede GIF encoding and optimization, with automatic frame reduction last. Clearing cached GIFs keeps records; clearing history removes records and their files. Existing disk downloads and active tasks are preserved. Requires Chrome 148+ and developer-mode installation. Full YouTube download acceptance, Shorts and the remaining native-site upgrade/permission flows are still pending. Install the extension ZIP; the source ZIP is for source distribution.
