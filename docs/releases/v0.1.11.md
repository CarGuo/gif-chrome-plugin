# Gif Toolkit Chrome v0.1.11

修复损坏历史阻断全部任务、Worker 静默无响应，以及批量保存中单项失败影响其他项目的问题。要求 Chrome 148+。

- 损坏历史单独显示并可删除，其他历史和生成继续可用；保留原记录供查看，不自动重置参数。
- Worker 超时会终止对应工作并继续队列；真实下载 / 解码进度可延长当前操作期限。
- 空名称和 Chrome 保存失败按项报告名称、原因；成功项退出选择、失败项保留，预览窗口保存防止重复提交。
- 编码进度写入失败保留原存储错误，不吞错或产生未处理拒绝。
- 所有普通版本 tag 发布正式 Release，包括 0.x。

类型检查、100 项单元 / 契约测试、九组 Chromium 回归、真实 Chrome 153 的故障恢复和批量保存测试通过；扩展包、固定第三方源码包及 SHA-256 已校验。浏览器回归使用隔离配置和测试素材。

来源信任边界、跨扫描命名、探测取消、异常下载引用恢复仍待后续修复；已有安装的登录态 X、YouTube 完整下载及 Shorts 验收缺口仍保留。详见仓库 `docs/REVIEW-2026-09-20-fixes.md`。
