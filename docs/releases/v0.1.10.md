# Gif Toolkit Chrome v0.1.10

本次预览版让结果区在结果增多时依然好用：Your GIFs 和历史结果改为有高度上限的独立滚动列表，并支持勾选后批量保存；同时修复同页多个视频默认名称相同、难以区分的问题。需要 **Chrome 148+**，通过开发者模式安装。

## 下载与升级

下载 **`gif-toolkit-chrome-0.1.10.zip`**，解压后在 `chrome://extensions` 加载包含 `manifest.json` 的目录。已有安装请更新原目录并重载，刷新来源网页、重新打开侧栏，确认版本为 **0.1.10**。不要卸载再安装，以免丢失本地历史。

## 主要变化

- **结果列表独立滚动**：Your GIFs 和历史结果都有高度上限（约 260–560 px），列表内部单独滚动，保存工具栏位于列表外。窄侧栏不会因为结果增多而无限拉长；列表支持键盘聚焦滚动。
- **勾选后批量保存**：文件仍保留的完成结果支持逐项勾选、全选、取消选择和“保存所选”，同时保留单项“保存 GIF”和“保存全部”。勾选绑定的是任务 ID，而不是列表位置；被搜索隐藏、删除或清理的文件会自动退出选择。
- **批量保存可在关闭面板后继续**：点击保存时把当时勾选的任务 ID / 名称一次性交给后台，由后台逐项读取对应文件提交下载；中途关闭或筛选面板不会改变已提交的清单。每项独立报告结果，未能开始的项目会明确说明原因。重复保存由浏览器自动分配新文件名，不会覆盖已下载文件。
- **同名素材自动区分**：修复同页多个视频继承同一个页面标题、默认名称难以区分的问题。扫描合并各 frame 后，只为重复标题加上本地化的素材序号（如“素材 01 · 标题”），序号放在标题开头，避免长标题截断后再次撞名。磁盘文件仍保留生成时间戳和完整任务 ID。

默认仍为 **4 MB / 最长边 800 px / 10 fps / 1×**；处理顺序、丢帧、历史与清理能力不变。

## 验证与限制

类型检查、74 项单元 / 契约测试、生产构建及历史 / 偏好回归已通过；新增“结果选择与批量保存”浏览器回归并接入 CI。tag CI 会重新运行八组浏览器测试、打包及校验，通过后才发布附件。真实 Chrome 153 已在独立配置下验证四项生成、320 / 430 px 列表、只保存勾选项、同名与重复保存的磁盘字节、清理与筛选，以及关闭面板后继续保存。浏览器回归使用隔离素材，不代表所有真实网站均已验收。

- **已有安装升级后的登录态 X 原生侧栏流程仍待验收。**
- **YouTube SABR 已接入，但有效会话中的完整下载验收尚未通过；Shorts 仍待专项验收。** 本版不将这些项目标为完成支持。
- 每段调速后最多 600 个采样帧，原始输入最多 128 MiB；不支持 DRM、直播或无法完整获取的来源。未包含原视频单独导出、拼接、裁剪、片段预览或真实缩略图帧条。

**English:** This preview gives Your GIFs and history results a bounded, independently scrolling list with the save toolbar staying outside it, and adds checkbox-based batch saving. Selection is tied to task IDs, not row positions; hidden, deleted or cleared files leave the selection. A batch hands a fixed snapshot of IDs/names to the background, so closing or filtering the panel cannot change it, and items that fail to start are reported individually. Duplicate media titles on one page now get localized numbered prefixes after merging all frames. Defaults and the download-first pipeline are unchanged. Requires Chrome 148+ and developer-mode installation. Full logged-in X acceptance, YouTube full-download acceptance and Shorts remain pending. Install the extension ZIP; the source ZIP is for source distribution.
