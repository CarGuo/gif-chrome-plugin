# Gif Toolkit Chrome v0.1.12

在原有网页视频抓取之外，新增本地视频批量导入。要求 Chrome 148+。

- 点「从电脑批量导入视频」一次选择多个视频，自动读出尺寸和时长，与网页媒体并列勾选、剪片段、生成 GIF。
- 本地视频直接读文件，不联网、不申请网络权限，断网可用。
- 导入项跨会话保留，可反复生成；在片段标题行点「移除导入」删除，正在生成时不可删除。
- 修复本地视频任务进入历史后被误判为损坏记录的问题；网页来源的历史校验不变。
- 新增导入入口、本地视频标签、移除导入的中英文案。

类型检查、106 项单元 / 契约测试、生产构建通过。本地导入的真实 Chrome 人工验收待完成；此前 X 登录态、YouTube 完整下载及 Shorts 的验收缺口仍保留。

下载 `gif-toolkit-chrome-0.1.12.zip` 并更新原目录，在扩展管理页重载后刷新来源页面。不要卸载重装，以免清除本地历史和已导入的视频。第三方源码 ZIP 用于源码分发；GitHub 自动提供的 Source code 不能直接加载为扩展。
