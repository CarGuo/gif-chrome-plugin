# 使用指南

[返回 README](../README.md) · 适用于 v0.1.5 / Chrome 148+

## 安装、升级与版本确认

从 [v0.1.5 Release](https://github.com/CarGuo/gif-chrome-plugin/releases/tag/v0.1.5) 下载扩展 ZIP，解压后在 `chrome://extensions` 中开启开发者模式，再加载包含 `manifest.json` 的目录。源码安装则先按 [开发指南](DEVELOPMENT.md) 构建，再加载 `dist/`。

升级时保留原安装目录和扩展，在该目录更新文件并点击重载；刷新来源网页、关闭后重开侧栏，左上角应显示新版本。仅刷新网页不会让已打开的旧侧栏自动更新。不要在处理过程中重载扩展。

旧版未版本化设置中的 12 fps 会一次性迁移为 10 fps；此后手动选择 12 fps 会保留。旧设置中的丢帧选项补为关闭。历史任务保持其原有帧率。

## 选择素材和片段

- 网页视频：先让播放器出现画面，再在目标媒体上右键「生成 GIF…」。也可点工具栏图标扫描页面。
- GIF / WebP：在图片上右键或从列表选择；需要编辑范围时，先点「读取动图，选择片段」。只读取已经加载或当前可发现的媒体。
- 多素材：勾选多个卡片。每个素材独立设置片段，速度和压缩参数共用。
- 多片段：点「添加片段」，调整各段起止时间；一段生成一个 GIF，不拼接。
- 默认范围：已知时长的素材选完整一轮 / 全部时长，不从播放头自动截取 5 秒。

原片段独立播放预览和真实缩略图帧条尚未实现；现有横条表示选区。完成后可以预览实际生成的 GIF。

## 速度与帧率

速度在「已选片段」顶部，支持 0.1–10×，提供 0.5× / 1× / 1.5× / 2× / 3× 快捷按钮。

例如原片段 20 秒，2× 输出约 10 秒；0.5× 输出约 40 秒。起止时间始终表示原视频时间。速度应用于所有本次选中的片段，不修改网页播放器的播放速度。

帧率在「压缩设置」内，默认 10 fps，可选 1–30 fps。更高帧率通常更流畅，也需要更多取帧时间和文件空间。GIF 延时精度为 10 毫秒；小数帧率间隔会按这个精度表示。

## 文件体积与尺寸

| 设置 | 默认 / 范围 | 说明 |
| --- | --- | --- |
| 文件上限 | 默认 4 MB；1 / 2 / 4 MB 预设 | 4 MB = 4,000,000 字节；最终按实际字节校验 |
| 最长边 | 默认 800 px，16–800 px | 等比例缩小；宽高都受上限约束，不放大小图 |
| 帧率 | 默认 10 fps，1–30 fps | 超限后的自动优化可能降低实际帧率 |
| 速度 | 默认 1×，0.1–10× | 成品时长约为所选原始时长 ÷ 倍速 |
| 丢帧 | 默认关闭 | 额外减少画面帧，保持倍速后的总时长 |

处理顺序为：按倍速采样 → 尺寸限制 → 可选丢帧 → 调色板 / 帧差分压缩 → 校验体积。超限后才进一步降帧、缩图，再从原始采样帧压缩。不会缩短所选范围；无法达标时明确失败。

## 丢帧

| 选项 | 保留方式 |
| --- | --- |
| 关闭（默认） | 不主动删除采样帧；超限后仍可能自动降帧 |
| 移除重复帧 | 仅合并连续相同的完整画面，包含透明区域；不同时间重新出现的画面会保留 |
| 每 2 帧移除第 2 帧 | 移除第 2、4、6…帧，保留约一半 |
| 每 3 帧移除第 3 帧 | 移除第 3、6、9…帧，保留约三分之二 |
| 每 4 帧移除第 4 帧 | 移除第 4、8、12…帧，保留约四分之三 |

删除帧的停留时间并入前一保留帧。这个操作不额外加速，但周期删除会降低动作流畅度。设置在提交生成任务后记住；从历史「调整片段」会恢复该任务的设置。

## X / YouTube 右键适配

如果右键只出现网站自带菜单：

1. 点击 Chrome 工具栏的 Gif Toolkit。
2. 在侧栏点「始终为此网站启用视频右键菜单」，授予当前网站访问权限。
3. 刷新网页，让扩展在播放器注册右键事件前生效。
4. 在视频画面上右键；按住 Alt 再右键可使用网站原菜单。

正文、链接和播放器操作按钮保持原有行为。图片来自其他 CDN 时，读取原文件可能另外请求图片来源权限。

X 真实登录态完整流程、Shorts 和跨域 iframe 仍待专项验收；不要把页面结构测试通过理解为所有平台页面都已支持。

## 文件名、历史和下载

生成前可编辑每个素材的「GIF 名称」，成品卡片保存前也可改名。X 优先使用媒体所属帖子的正文，其他网页使用有意义的媒体标题、说明或页面标题。

磁盘文件名为：

```text
Base64url(标题前缀)_生成时间戳_任务唯一编号.gif
```

标题先按完整 UTF-8 字符截取到最多 72 字节再编码；使用 Base64url 避免 `/` 等路径字符，不含中文、空格、`+` 或 `=`。生成时间为任务创建时的 Unix 毫秒数，每个新任务有独立编号；重复下载或改名保存不会改变生成时间。界面继续显示完整可读标题。

默认下载目录为 Chrome 下载目录下的 `GifToolkit/`。选择「另存为」可更改保存位置。浏览器自身的下载设置可能改变保存提示行为。

关闭侧栏后任务继续处理；取帧期间来源页面必须保持打开。保留最近 30 个已结束任务及成品，可逐条删除。删除历史不会删除已保存到磁盘的文件。退出浏览器、重载扩展或崩溃中断的任务需要重新生成。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 界面还是旧版本 | 重载扩展，刷新来源页面，再重开侧栏；检查左上角版本 |
| 找不到视频 | 先播放出画面，再扫描；懒加载媒体需先滚动到所在位置 |
| 提示超过帧数预算 | 单段最多 600 个调速后的采样帧；提高倍速、降低帧率或缩短选区；额外丢帧不能跳过前期采样预算 |
| 图片下载 / 权限失败 | 检查是否允许图片来源或 CDN；原站拒绝请求、过期链接等仍可能失败 |
| 页面视频在来回跳转 | 正在按时间点取帧；结束 / 取消后恢复播放器；取帧期间不要手动切换到其他视频 |
| 来源已改变 | 网页复用了播放器节点或已经导航；重新扫描、选择新素材 |
| 无法读取像素 | 播放器跨域策略或 DRM 可能阻止导出；扩展不会绕过这些限制 |
| 文件仍无法达到限制 | 该画面的复杂度超出搜索范围；提高文件上限或自行降低参数 |
| 透明 WebP 边缘变化 | GIF 仅支持二值透明，不能完整表达 WebP 的半透明像素 |

反馈问题时提供 Chrome / 扩展版本、素材类型、所选范围、速度 / 帧率 / 体积参数、错误提示和可公开的复现链接。不要上传 token、Cookie 或私人媒体。
